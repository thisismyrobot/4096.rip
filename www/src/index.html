BiLock FG Key Profile Generator

Enter the left and right profiles, separated by a space.

STL Files

What is this?

This is a generator for 3D-printable keys for BiLock's First Generation (FG) Locks. It's an experiment so YMMV.

Step-by-Step Instructions

Enter two six-digit profiles separated by a space. Each digit must be between 1 and 4. The first digit of a profile is the tip of the key.

  • Example input: 121212 343434
  • Press Generate to preview downloadable STL files.

Why 4096.rip?

There are 46 = 4096 possible profiles for each side of a BiLock FG key, which is a lot less mathematically spooky than the 16 million possible combinations you get when you combine both sides, and I'd rather generate 4096 STLs than 16 million.
